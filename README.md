# Energy Calculator

A Python program that calculates a household's daily and monthly
electricity use and cost from a list of appliances.

## What it does

- Calculates kWh for each appliance from its wattage and hours of use
- Flags appliances using more than 1 kWh per day
- Finds the biggest energy user and its share of the total
- Calculates a monthly bill using a tiered tariff

## How to run

1. Install Python
2. Edit the appliance lists at the top of the file
3. Run: `python energy_calculator.py`
